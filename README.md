# DIMSTORY - Si Kelinci yang Sombong dan Kura-kura

Fabel klasik Kiki si Kelinci sombong rompi merah vs Tora si Kura-kura bijak kacamata, jadi storyboard 9:16 portrait siap upload TikTok/Reels/Shorts.

## Fitur
- 12 scene 9:16 portrait, 3 PART (Ejekan Biru, Perlombaan Hijau, Kemenangan Ungu)
- Prompt full per scene (adegan + dialog Bahasa Indonesia + rasio)
- Character sheet Kiki & Tora bisa download
- Export PNG/JPG HD
- Guest Mode - Masuk sebagai Pengunjung tanpa Gmail wajib
- BYO API Gemini 3.8 Flash / OpenAI Compatible + Test Koneksi
- White-blue clean theme, soft animasi tombol

## Cara Jalan
npm install
npm run dev
Buka http://localhost:3000
- / -> Landing page
- /welcome -> Pilih Guest atau Gmail opsional
- /app -> Daftar cerita
- /app/create -> MAU BUAT CERITA APA (default Kiki & Tora)
- /app/story/demo -> Demo 12 scene Kiki & Tora

## Guest Mode
Tidak perlu Gmail. Data disimpan di browser (IndexedDB). Aman, gratis, langsung pakai.
